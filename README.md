# Image-to-Text React App

A React-based **image-to-text interface** for uploading an image and presenting extracted text. The project uses Tesseract.js for browser-based OCR experimentation.

## Features

- Image upload with click or drag-and-drop
- Image preview and removal
- OCR-oriented image-to-text workflow
- Text copy component
- Responsive Bootstrap-based styling
- User feedback with toast notifications

## Tech Stack

- React
- JavaScript
- Tesseract.js
- Bootstrap / React-Bootstrap
- React Icons
- React Toastify

## Run Locally

```bash
npm install
npm start
```

Open **http://localhost:3000**.

## Note

This repository represents an early **OCR/image-to-text project** and is best viewed as a frontend experimentation project rather than a production-ready OCR platform.
